# BU CS455/655 Personal Notes

My name is Jiafei Fan, and I am a teaching assistant for Boston University's CS455/655 in Summer 2027 and Fall 2027. This repository contains my personal notes for students to use as a reference. The notes may contain errors.

Some images in these notes come from *Computer Networking: A Top-Down Approach* by Jim Kurose and Keith Ross and Professor Fan Yang's lecture slides. All rights to these images belong to their respective owners.

For the best viewing experience, open this repository in Visual Studio Code and install the **Markdown Image Size** extension, then use Markdown Preview to read the notes.
